# Office SDK Documentation

Choose a language to read the Office SDK developer documentation.

- [简体中文](./zh-CN/README.md)
- [English](./en-US/README.md)

## Structure

The documentation uses a locale-first structure:

- `zh-CN/`: Simplified Chinese documentation
- `en-US/`: English documentation

Keep both locale folders aligned when adding or renaming pages so the generated HTML language switcher can point to the same page in each language.
